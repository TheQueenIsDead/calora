# Calora

A Flutter calorie and nutrition tracking app for iOS and Android. Log meals, track water intake, scan barcodes, build recipes, and monitor trends — all stored locally with no account required.

## Features

- **Daily diary** — log food across Breakfast, Lunch, Dinner, and Snacks with drag-to-reorder between meals
- **Calorie ring** — at-a-glance progress toward your daily calorie goal with macro breakdown (carbs, protein, fat)
- **Barcode scanning** — scan packaged food and pull nutrition data from [Open Food Facts](https://world.openfoodfacts.org/)
- **Food search** — search the bundled food database or Open Food Facts
- **Water tracking** — log intake with customisable vessels (glass, bottle, mug, etc.) and a daily target
- **Recipes** — save any meal as a recipe with configurable servings; add recipes back to the diary as a single entry
- **BMR / TDEE calculator** — estimate daily calorie needs from body stats
- **Trends** — weekly and monthly charts for calories and macros
- **Day locking** — past days lock automatically; tap the lock icon to unlock for edits
- **Light and dark theme** — follows system appearance via Material 3

## Colour palette

The app is built on a single seed colour using Material 3's `ColorScheme.fromSeed`, which derives the full tonal palette automatically.

| Role            | Colour          | Hex        |
| --------------- | --------------- | ---------- |
| Seed / Primary  | Forest Green    | `#2E7D32`  |
| Water indicator | Light Blue 400  | `#29B6F6`  |
| Water goal met  | Light Green 300 | `#AED581`  |
| Carbohydrates   | Material Blue   | `#2196F3`  |
| Protein         | Material Orange | `#FF9800`  |
| Fat             | Material Purple | `#9C27B0`  |

Light and dark schemes are both seeded from `#2E7D32`; surface tones, containers, and on-colours are generated by Flutter's `ColorScheme.fromSeed`.

## Tech stack

| Layer             | Library                                              |
| ----------------- | ---------------------------------------------------- |
| UI framework      | Flutter 3.41.8 · Material 3                          |
| State management  | `provider`                                           |
| Local database    | `sqflite` (two DBs: seed food catalogue + user data) |
| Preferences       | `shared_preferences`                                 |
| Barcode scanning  | `mobile_scanner`                                     |
| Nutrition API     | Open Food Facts v2 (`http`)                          |
| Charts            | `fl_chart`                                           |
| Icons             | Material Icons · `flutter_svg`                       |

## Project structure

```
lib/
  main.dart               # App entry, theme setup, bottom nav
  models/                 # DiaryEntry, FoodItem, WaterVessel
  providers/
    diary_provider.dart   # Central state: entries, water, lock, vessels
  screens/
    home_screen.dart      # Diary + water card + week strip
    trends_screen.dart    # Charts
    settings_screen.dart  # Recipes, water settings, BMR calculator
    recipes_screen.dart   # Recipe detail + servings editor
    add_food_screen.dart  # Search + barcode entry point
    barcode_scan_screen.dart
    food_detail_screen.dart
    bmr_calculator_screen.dart
    water_vessels_screen.dart
  services/
    database_service.dart # SQLite: foods DB (seed) + user DB (diary/recipes)
    food_lookup_service.dart # Open Food Facts API
  widgets/
    calorie_ring.dart
    meal_section.dart
assets/
  calora_seed.db          # Bundled food catalogue (read-only)
  logo.svg / logo.png     # App icon source
```

## Getting started

**Prerequisites:** Flutter 3.41.8 stable

```bash
flutter pub get
flutter run
```

Launcher icons are pre-generated. To regenerate after changing `assets/logo.png`:

```bash
dart run flutter_launcher_icons
```

## CI

GitHub Actions runs `dart analyze --fatal-infos` and `flutter test` on every push and pull request to `main`. The Flutter version is pinned via `pubspec.yaml`.
